Emojipedia is a small React practice project that lists emojis with their names and meanings. Each card is a reusable Entry component that receives its data through props, and the cards are generated by mapping over an array of emoji data. It was built to practise React components, props, map() with keys, and CSS styling.

Built with: React, JavaScript (ES6), CSS

Live demo: https://nhpdvl.csb.app/
